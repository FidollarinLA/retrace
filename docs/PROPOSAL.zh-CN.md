# ReTrace：基于 MoonBit 的可复算 AI 数据报告引擎
- 参赛方向：数据处理 / AI 应用 / 可复用工具库。
- 作者：FidollarinLA（翟继康）；新建独立开源项目。
- 仓库：https://github.com/FidollarinLA/retrace
- 项目目标：让 AI 数据报告中的数字具有明确计算依据，能够回到原始记录重新执行与核验。
- 用户问题：图表或报告更新后，读者难以检查数字对应的数据、筛选条件、计算公式及缺失值处理；模型生成数字可能与实际结果不一致。
- 核心实现：MoonBit 完成 CSV 解析、严格分析配置验证、派生计算、筛选分组、统计聚合、记录级来源和结构化 AI 数字核验。
- 产品体验：浏览器本地导入数据、修改分析、检查证据、导出 HTML 与 JSON 报告包、重新导入复算和识别不一致。
- 通用示例：销售业绩、实验测量、电机温升共用同一个引擎；示例全部为合成数据。
- AI 边界：可导出证据提示词或连接用户配置的模型端点；仅核验结构化数字、单位和证据引用，不认证自由文本或因果判断。
- 独立贡献：以可执行分析配置和 MoonBit 核心为基础，把证据记录、复算包和数值核验连接为完整工作流；非现有项目移植。
- 参考来源：DataMagic 的数据绑定叙事体验；未复制其代码、模板或规范。
- 已实现：七种聚合、AND 筛选、四种派生运算、严格错误处理、三场景界面、命令行、可选 AI 适配器和自动化测试。
- 验证计划：MoonBit JS / Wasm-GC 测试、与独立 Python 统计实现对照、报告篡改与错误模型响应测试；GitHub Actions 持续运行。
- 初始验证：15 项 MoonBit 测试分别在 JS 与 Wasm-GC 通过，16 项集成检查，560 个固定种子参考场景、1673 个聚合及来源对照。
- 可复现命令：`npm run build && npm start`；`moon run cmd/retrace`；README 提供测试、CLI 与可选 AI 接入说明。
- 开源许可证：Apache-2.0；合成数据使用同一许可证，MoonBit core 按其 Apache-2.0 许可使用。
- 后续阶段：基于反馈完善数据预览、自然语言分析计划生成和更细的证据交互；不宣称已有真实客户或工业验证。
